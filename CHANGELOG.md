# Release notes

## 1.0.0

- Record, undo, and retrospectively confirm medication intakes. Browse the
  date-based archive with the medication and schedule details valid on each day.
- Configure multiple independent slots and optional Android reminders, with an
  explicit **Taken** action and adjustable snooze for each slot.
- Manage records offline, including JSON backup, restore, and deletion.
- Choose German or English, a theme, and an accent colour. Read the privacy
  policy, medical limitations, and open-source licences inside the app.
- Existing installs retain Drift schema v4 and version 1 JSON backup
  compatibility. Follow the release guide for Android signing and web deployment.
